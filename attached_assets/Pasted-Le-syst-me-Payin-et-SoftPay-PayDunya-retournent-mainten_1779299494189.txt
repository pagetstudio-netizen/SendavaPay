Le système Payin et SoftPay PayDunya retournent maintenant :

Unexpected token '<', "<!DOCTYPE "... is not valid JSON

Cela signifie que certaines requêtes API PayDunya reçoivent une page HTML (probablement page login, erreur nginx, endpoint web ou route invalide) au lieu d’une réponse JSON.

IMPORTANT :
Le système ne doit plus jamais parser du HTML avec response.json().
